GitHub split button — mockup

Proposal for the header's Save to GitHub / Copy share link control. Pick a state, then click the button, the chevron, or the menu items. Keyboard: Tab to the button, Enter/↓ on the chevron opens the menu, ↑/↓ move, Esc closes.

Notes for implementation

  • Two real <button>s in one group. Chevron: aria-haspopup="menu", aria-expanded, aria-controls; menu role="menu", items role="menuitem"; focus returns to the chevron on close.
  • Colours are the workbench tokens: white button with --wb-accent-dark text on the --wb-header-bg gradient (a blue button on a blue header would not stand out); hover --wb-accent-soft.
  • The status chip in the menu header is the same GitHubStatus component as on the project page.
  • Shortcut suggestion: Ctrl+Shift+S = Save to GitHub (works in this mockup; named in the tooltip).
  • Below 900 px the label can shrink to the icon only, with the label kept in aria-label.
